## Authentication, roles and RLS
- No login/invitation/session refresh/logout backend integration or Supabase SDK dependency found. package.json contains Next/React/motion dependencies, no Supabase client.
- workspace-role-preview.tsx reads/writes demo identity in localStorage and syncs appearance cookies. It is presentation state, not a verified principal. Role selector visibility in development and production role labels do not create authorization.
- SQL user_accounts links auth_subject to Auth in the later foundation. require_operator uses auth.uid(), enabled accounts and current centre grants. This is implemented private SQL authorization logic, not an operational Auth integration.
- 006 maps owner_admin→admin and teacher_invigilator→teacher, retains non-developer grant history and freezes legacy assignments. Legacy developer does not imply business authority. Platform grants are separate with no implicit centre Admin rights.
- manage_centre_role is Admin-only, rejects self-administration and privileged role choices, allows Manager/Teacher/Student grant/revoke with reason, idempotency and audit records. Admin/Platform Owner provisioning is deliberately absent.
- All 21 locally defined private tables are covered by ENABLE/FORCE RLS. No CREATE POLICY statements or application access grants found. PUBLIC schema/table/function access is revoked; default privileges restrict future objects. Private workflow helpers use SECURITY INVOKER and constrained search_path; no privileged exposed SECURITY DEFINER RPC found.
- Default deny is a protective boundary, not completed own-student/assigned-teacher/admin/manager policy implementation. An ordinary application caller cannot simply use these functions without a reviewed endpoint and compatible narrow grants/policies. Infrastructure owner/BYPASSRLS access is outside this guarantee.
- Student A/B separation in the frontend does not verify real account ownership or database isolation. Actual JWT, MFA, session revocation, assignment revocation races and least-privilege endpoint behavior remain unverified.
